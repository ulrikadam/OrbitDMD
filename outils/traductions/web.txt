# Traductions de l'interface web d'OrbitDMD
#
# Une ligne par texte :  francais | anglais | neerlandais | espagnol | russe
# Le francais est le texte exact de la page. "{}" : partie variable (nombre, nom...) ;
# la traduction reprend les parties dans l'ordre avec "{}", ou dans un autre ordre avec
# "{1}", "{2}"... Une case vide : le texte reste en francais.
# Apres une modification : make -C dmd (outils/langues.py ecrit dmd/web/lang-xx.js).
# Corrections bienvenues : https://github.com/ulrikadam/OrbitDMD/issues
