# OrbitDMD и Home Assistant

[Français](HOME-ASSISTANT.md) · [English](HOME-ASSISTANT.en.md) · [Nederlands](HOME-ASSISTANT.nl.md) · [Español](HOME-ASSISTANT.es.md) · **Русский** · [Deutsch](HOME-ASSISTANT.de.md) · [Italiano](HOME-ASSISTANT.it.md) · [Português](HOME-ASSISTANT.pt.md) · [Polski](HOME-ASSISTANT.pl.md) · [Українська](HOME-ASSISTANT.uk.md) · [Türkçe](HOME-ASSISTANT.tr.md) · [Čeština](HOME-ASSISTANT.cs.md)

Начиная с версии 1.4.0 панель подключается к Home Assistant по **MQTT** и появляется там сама
(автоматическое обнаружение). Названия сущностей следуют языку панели (Настройки → Экран → Язык панели).

## Подключение

1. В Home Assistant: **Настройки → Дополнения → Магазин дополнений**, установите и запустите
   **Mosquitto broker**. Затем добавьте интеграцию **MQTT**, если Home Assistant не предложит её сам.
2. Создайте пользователя для панели (**Настройки → Люди → Пользователи**), например `orbitdmd`.
3. На веб-странице панели: **Настройки → Home Assistant**: включите, укажите **IP-адрес**
   Home Assistant (например, `192.168.0.10`), порт `1883`, пользователя и его пароль, затем сохраните.
   Панель перезапустится и подключится.
4. В Home Assistant: **Настройки → Устройства и службы → MQTT → OrbitDMD**.

На веб-странице панели есть также страница **Справка Home Assistant** (`http://<панель>/aide`): все
команды и готовые примеры с настоящим именем вашей панели.

Карточка Home Assistant на странице «Настройки» показывает, работает ли подключение. При проблемах
журнал на странице «Система» содержит строки `homeassistant`.

## Что появляется в Home Assistant

| Сущность | Тип | Назначение |
|---|---|---|
| Панель | свет | Включить, выключить (веб-страница остаётся доступной), задать яркость |
| Яркость по часам | переключатель | Вкл.: яркость следует почасовым настройкам панели. Изменение яркости из Home Assistant отключает его |
| Пауза | переключатель | Заморозить изображение |
| Показать время, Показать погоду | кнопки | Сразу, на 15 секунд |
| Перезапуск | кнопка | |
| Сообщение | уведомление | Сразу показать текст |
| Текст для показа | текст | Введите текст в Home Assistant и подтвердите: он сразу появится |
| Эффект, Цвет, Проходы, Скорость сообщений | списки и числа | Стиль текстов из Home Assistant (сохраняется после перезапуска) |
| Текст: …, Отсчёт: … | переключатели | Включение и выключение каждого текста и отсчёта со страницы «Сообщения» |
| Команды MQTT | датчик (диагностика) | Список всех команд в атрибутах |
| Текущий GIF, Экран | датчики | Что показывает панель |
| Температура процессора, IP-адрес, Версия | датчики (диагностика) | |

Если панель выключена или отключена от сети, Home Assistant показывает её как «недоступно».

## Сообщения

Проще всего — в автоматизации:

```yaml
action: notify.send_message
target:
  entity_id: notify.orbitdmd_message
data:
  message: "Звонят в дверь!"
```

(точное имя сущности видно на странице устройства OrbitDMD).

Стиль (эффект, цвет, проходы, скорость) берётся из элементов «… сообщений» устройства. Для
отдельного стиля одного сообщения опубликуйте JSON в топик `orbitdmd/<имя>/notification`
(`<имя>` — сетевое имя панели строчными буквами):

```yaml
action: mqtt.publish
data:
  topic: orbitdmd/orbitdmd/notification
  payload: >
    {"message": "Стирка закончена", "effet": "pluie", "couleur": "arc-en-ciel", "passages": 2}
```

| Поле | Значения | По умолчанию |
|---|---|---|
| `message` | текст (не более 200 байт; русская буква занимает 2 байта) | |
| `effet` (эффект) | `defile`, `inverse`, `monte`, `descend`, `lettres`, `pluie`, `fondu` (влево, вправо, вверх, вниз, по буквам, дождь из букв, плавно) | `defile` |
| `couleur` (цвет) | `FF8000` (красный-зелёный-синий) или `arc-en-ciel` (радуга) | белый |
| `police` (шрифт) | `Pixel` или файл шрифта на панели, например `PressStart2P.ttf` (с кириллицей) | `Pixel` |
| `taille` (размер) | размер в пикселях, `0` = автоматически | `0` |
| `vitesse` (скорость) | от 1 (медленно) до 10 (быстро) | 5 |
| `passages` (проходы) | от 1 до 10 | 2 |
| `gif` | GIF перед текстом: `Категория/имя.gif` | нет |

Сообщение показывается сразу, поверх GIF, затем ротация продолжается. Если панель выключена или на
паузе, сообщение ждёт, пока её снова включат.

## Примеры автоматизаций

- Уменьшить яркость на закате: действие `light.turn_on` для «Панель» с `brightness_pct: 20`.
- Выключать панель, когда все ушли из дома: `light.turn_off`.
- Дверной звонок: сообщение «Звонят в дверь!» с `"gif": "Accueil/zvonok.gif"` (GIF, который вы
  добавили в любую категорию).

## Ограничения

- Подключение MQTT не шифруется (нет TLS): используйте его в домашней сети.
- Адрес `homeassistant.local` не работает: укажите IP-адрес Home Assistant.
