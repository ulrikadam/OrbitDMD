# OrbitDMD і Home Assistant

[Français](HOME-ASSISTANT.md) · [English](HOME-ASSISTANT.en.md) · [Nederlands](HOME-ASSISTANT.nl.md) · [Español](HOME-ASSISTANT.es.md) · [Русский](HOME-ASSISTANT.ru.md) · [Deutsch](HOME-ASSISTANT.de.md) · [Italiano](HOME-ASSISTANT.it.md) · [Português](HOME-ASSISTANT.pt.md) · [Polski](HOME-ASSISTANT.pl.md) · **Українська** · [Türkçe](HOME-ASSISTANT.tr.md) · [Čeština](HOME-ASSISTANT.cs.md)

Починаючи з версії 1.4.0 панель підключається до Home Assistant через **MQTT** і з'являється там сама
(автоматичне виявлення). Назви сутностей відповідають мові панелі (Налаштування → Екран → Мова панелі).

## Підключення

1. У Home Assistant: **Налаштування → Доповнення → Магазин доповнень**, установіть і запустіть
   **Mosquitto broker**. Потім додайте інтеграцію **MQTT**, якщо Home Assistant не запропонує її сам.
2. Створіть користувача для панелі (**Налаштування → Люди → Користувачі**), наприклад `orbitdmd`.
3. На вебсторінці панелі: **Налаштування → Home Assistant**: увімкніть, вкажіть **IP-адресу** Home Assistant
   (наприклад, `192.168.0.10`), порт `1883`, користувача та пароль, потім збережіть. Панель перезапуститься
   і підключиться.
4. У Home Assistant: **Налаштування → Пристрої та служби → MQTT → OrbitDMD**.

На вебсторінці панелі є також сторінка **Довідка Home Assistant** (`http://<панель>/aide`): усі команди
й готові приклади зі справжнім ім'ям вашої панелі.

Картка Home Assistant на сторінці «Налаштування» показує, чи працює підключення. У разі проблем журнал на
сторінці «Система» містить рядки `homeassistant`.

## Що з'являється в Home Assistant

| Сутність | Тип | Призначення |
|---|---|---|
| Панель | світло | Увімкнути, вимкнути (вебсторінка доступна), задати яскравість |
| Яскравість по годинах | перемикач | Увімк.: яскравість іде за почасовими налаштуваннями. Зміна яскравості з Home Assistant вимикає його |
| Пауза | перемикач | Заморозити зображення |
| Показати час, Показати погоду | кнопки | Одразу, на 15 секунд |
| Перезапуск | кнопка | |
| Повідомлення | сповіщення | Одразу показати текст |
| Текст для показу | текст | Введіть текст у Home Assistant і підтвердьте: він одразу з'явиться |
| Ефект, Колір, Проходи, Швидкість повідомлень | списки й числа | Стиль текстів із Home Assistant (зберігається після перезапуску) |
| Текст: …, Відлік: … | перемикачі | Увімкнення кожного тексту й відліку зі сторінки «Повідомлення» |
| Команди MQTT | датчик (діагностика) | Список усіх команд в атрибутах |
| Поточний GIF, Екран | датчики | Що показує панель |
| Температура процесора, IP-адреса, Версія | датчики (діагностика) | |

Якщо панель вимкнена чи відключена, Home Assistant показує її як «недоступна».

## Повідомлення

Найпростіше — в автоматизації:

```yaml
action: notify.send_message
target:
  entity_id: notify.orbitdmd_message
data:
  message: "Дзвонять у двері!"
```

(точне ім'я сутності видно на сторінці пристрою OrbitDMD).

Стиль (ефект, колір, проходи, швидкість) береться з елементів «… повідомлень». Для окремого стилю одного
повідомлення опублікуйте JSON у топік `orbitdmd/<ім'я>/notification` (`<ім'я>` — мережеве ім'я панелі
малими літерами):

```yaml
action: mqtt.publish
data:
  topic: orbitdmd/orbitdmd/notification
  payload: >
    {"message": "Прання завершено", "effet": "pluie", "couleur": "arc-en-ciel", "passages": 2}
```

| Поле | Значення | Типово |
|---|---|---|
| `message` | текст (не більше 200 байт; кирилична літера займає 2) | |
| `effet` (ефект) | `defile`, `inverse`, `monte`, `descend`, `lettres`, `pluie`, `fondu` (ліворуч, праворуч, вгору, вниз, по літерах, дощ із літер, плавно) або назви з Home Assistant | `defile` |
| `couleur` (колір) | `FF8000` (червоний-зелений-синій), `arc-en-ciel` (веселка) або назва кольору з Home Assistant | білий |
| `police` (шрифт) | `Pixel` або файл шрифту на панелі, наприклад `PressStart2P.ttf` (з кирилицею) | `Pixel` |
| `taille` (розмір) | розмір у пікселях, `0` = автоматично | `0` |
| `vitesse` (швидкість) | від 1 (повільно) до 10 (швидко) | 5 |
| `passages` (проходи) | від 1 до 10 | 2 |
| `gif` | GIF перед текстом: `Категорія/ім'я.gif` | немає |

Повідомлення показується одразу, поверх GIF, потім ротація продовжується. Якщо панель вимкнена чи на паузі,
повідомлення чекає.

## Приклади

- Зменшити яскравість на заході сонця: `light.turn_on` для «Панель» з `brightness_pct: 20`.
- Вимикати панель, коли всі пішли з дому: `light.turn_off`.
- Дверний дзвінок: повідомлення «Дзвонять у двері!» з `"gif": "Accueil/dzvinok.gif"` (GIF, який ви додали).

## Обмеження

- Підключення MQTT не шифрується (немає TLS): використовуйте його в домашній мережі.
- Адреса `homeassistant.local` не працює: вкажіть IP-адресу Home Assistant.
