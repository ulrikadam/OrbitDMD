Sans rien écrire

Dans Home Assistant : Paramètres → Appareils et services → MQTT → OrbitDMD. Tout se fait depuis cette page :

ÉlémentCe qu'il fait
PanneauAllumer, éteindre (la page web reste joignable), luminosité
PauseAllumé : image figée ; éteint : lecture normale
Texte à afficherTapez un texte et validez : il défile tout de suite
Effet, Couleur, Passages, Vitesse des messagesLe style des textes envoyés depuis Home Assistant
Texte : …, Compte à rebours : …Activer ou non chaque élément de la page Messages
Afficher l'heure, Afficher la météoTout de suite, pendant 15 secondes
Luminosité heure par heureRevenir à la luminosité des réglages après un changement depuis Home Assistant
RedémarrerRedémarre le panneau

Envoyer un message

Le plus simple, dans une automatisation ou dans Outils de développement → Actions (mode YAML) :


			
Avec un style à part (couleur, effet, GIF avant le texte) :

			

			

				
ChampValeurs

				
messageLe texte (200 caractères au plus, accents compris)

				
effetdefile, inverse, monte, descend, lettres, pluie, fondu

				
couleurBlanc, Rouge, Orange, Ambre, Jaune, Vert, Turquoise, Bleu, Violet, Rose, arc-en-ciel, ou FF8000

				
policePixel ou une police de la page Horloge, par exemple Orbitron.ttf

				
tailleTaille en pixels, 0 = automatique

				
vitesse, passages1 à 10

				
gifUne GIF à jouer avant le texte : Categorie/nom.gif (comme dans la page GIF)

			

			
Les champs absents prennent le style réglé dans Home Assistant (Effet, Couleur, Passages, Vitesse des messages). Si le panneau est éteint ou en pause, le message attend.
