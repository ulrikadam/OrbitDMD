Home Assistant

Il faut le module Mosquitto broker dans Home Assistant (Paramètres → Modules complémentaires) et l'intégration MQTT. Le panneau redémarre pour se connecter. Ensuite, dans Home Assistant : Paramètres → Appareils → OrbitDMD. Toutes les commandes et des exemples à copier : page Aide Home Assistant.

Réseau

.local

Conseil : dans votre box, réservez cette adresse pour le panneau (adresse MAC —), pour qu'elle ne soit jamais donnée à un autre appareil.

Le câble est choisi au démarrage : après l'avoir branché ou débranché, redémarrez le panneau. Après un changement de connexion, de Wi-Fi ou d'adresse, le panneau redémarre. S'il n'est pas joignable en 2 min 30, il revient tout seul aux anciens réglages.
